## Proyecto
IA HUNTER - Evasión Algorítmica

Juego por turnos en cuadrícula donde el jugador debe evadir a tres enemigos controlados por IA (A*, BFS, DFS) y llegar a la meta. Los enemigos usan un Árbol de Comportamiento para decidir si perseguir o patrullar, y algoritmos de búsqueda para calcular sus rutas.
